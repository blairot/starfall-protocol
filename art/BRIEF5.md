# Starfall Protocol: art brief, part 5 (23 new cards + 1 pack)

Twenty-three new cards and the front of a new pack:
- **The Choir set (12 cards):** the final sector's own cards, sold in the new Singularity Pack.
- **Elite Legendaries (11 cards):** each optional Elite mission now awards its commander as a Legendary card.

These are **card art**, exactly like the cards you already painted.

## Before you start

1. Re-read **art/BRIEF.md**: "Art direction", "Technical specs" and "Readability at small size". Everything there applies: landscape 1536 x 1024 (the game crops to 16:10), painterly AAA concept-art finish, key plus rim lighting, and no text, logos, frames or watermarks.
2. **The Choir look** (all 12 set cards): black glass and obsidian, polished and cracked, lit from inside by violet and magenta light, with hair-thin glowing seams. Forms are human, machine or Swarm shapes remade in glass, as if the Choir copied them from memory: beautiful, quiet and wrong. Style references: `art/incoming/portrait-the-choir-awakened.png`, `art/incoming/choir_echo.png`, `art/incoming/sector-s6.png`.
3. **Elite Legendaries:** paint the same character as their existing enemy portrait, now as a full card-art scene (a heroic three-quarter shot in action, not a head-and-shoulders portrait). The portrait file named for each one is the reference. They're Legendary: make them feel special and iconic.
4. Every card must look clearly different from every existing card. No reused faces, poses or compositions.
5. Save each one to **art/incoming/** with the exact file name below, and add a line per image to `art/incoming/_log.csv`.
